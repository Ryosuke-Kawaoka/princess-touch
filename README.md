# プリンセス・タッチゲーム

上から落ちてくるプリンセスの中から、選んだプリンセスをタッチするブラウザゲームです。

## ゲーム内容

- プリンセス：アリエル、ラプンツェル、ジャスミン、白雪姫
- プレイ時間：10秒／20秒
- 難易度：やさしい／ふつう／むずかしい
- スマートフォン、タブレット、パソコンの縦・横画面に対応

## GitHubへアップロードする方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルとフォルダを、構成を変えずにすべてアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
5. Branchを `main`、フォルダを `/(root)` にして `Save` を押します。
6. 数分後、GitHub PagesのURLから遊べます。

## ローカルで確認する方法

`index.html` をブラウザで開くだけでも動作します。ブラウザの制限がある場合は、VS CodeのLive Serverなどでこのフォルダを開いてください。
